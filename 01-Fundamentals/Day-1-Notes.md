# Fundamentals of Software Testing: Why Testing is Necessary

## 1. What is Software Testing?
Software testing is not just about finding bugs; it is a process to verify that the software meets user requirements, functions reliably under normal conditions, and handles unexpected or extreme scenarios without failing.

## 2. Rigorous Testing Approach
Rigorous testing is an uncompromising, deep testing approach applied to critical systems. Instead of relying on a single method, it combines boundary analysis, negative testing, load testing, and security checks to uncover hidden defects before release.

---

## 3. Real-World Case Studies (Impact of Software Failures)

### Case 1: China Airlines Airbus A300 Crash (1994)
* **Impact:** 264 lives lost.
* **Root Cause:** A software logic flaw in the autopilot system conflicted with manual pilot inputs during landing.
* **QA Takeaway:** In safety-critical systems (aviation, healthcare), software reliability is a matter of life and death, making rigorous testing non-negotiable.

### Case 2: Military Satellite Launch Failure (1999)
* **Impact:** $1.2 Billion financial loss.
* **Root Cause:** A minor coding/decimal error placed the satellite into an unusable orbit.
* **QA Takeaway:** The cost of fixing a defect after release (or failing to test thoroughly) is exponentially higher than investing in comprehensive QA upfront.

### Case 3: Bloomberg Terminal Crash (2015)
* **Impact:** 300,000+ traders disrupted; £3 Billion UK government debt sale postponed.
* **Root Cause:** A system-wide software failure in interconnected financial infrastructure.
* **QA Takeaway:** Modern systems are heavily interconnected. A single defect can trigger a ripple effect across global markets, highlighting the need for thorough integration and system testing.
